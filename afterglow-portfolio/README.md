# AFTERGLOW — Kumar Akhilesh portfolio

A responsive React + TypeScript portfolio concept inspired by the colourful, optimistic internet atmosphere of 2016–2021. Includes a cinematic CSS landscape, responsive navigation, animated sections, category-filtered project gallery, six project detail routes, a timeline, and optional original synthesised ambient tones (off by default).

## Run locally

1. Install Node.js 20 or newer.
2. Open a terminal in this folder.
3. Run `npm install`.
4. Run `npm run dev` and open the local URL shown.
5. Run `npm run build` for a production bundle (`dist/`).

## Publishing checklist

- **Verify all biographical details and project status** in `src/data.ts` and `src/main.tsx`.
- Replace `hello@kumarakhilesh.com.np` with a verified contact address.
- Add genuine project screenshots, recordings, documentation and repository links. The current project art is illustrative, not photographic evidence.
- The supplied concept-board.png is a reference image only; the live website uses original CSS-generated visuals.
- Hash-based project routes (`#project/project-slug`) work on static hosting without rewrite rules.
- Sound is a minimal original browser-generated chord drone, not a licensed song or music track.
- Fonts are loaded from Google Fonts; for fully offline hosting, self-host licensed font files.

## Technology
React, TypeScript, Vite, CSS, Motion, lucide-react, Web Audio API.
